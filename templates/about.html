ABOUT FINDOC AI

Making financial document verification more explainable.

FinDocAI is an AI-powered prototype designed to identify suspicious visual patterns in financial documents.

THE TECHNOLOGY

EfficientNetV2B0

The system uses EfficientNetV2B0 as its image classification backbone. Financial documents are analyzed as image regions rather than relying only on extracted text.

EXPLAINABILITY

Grad-CAM

Grad-CAM provides a visual explanation of the model's attention by highlighting regions that contributed strongly to the prediction.

INPUT

Receipts & Invoices

Users can upload an image or capture a document using their device camera.

OUTPUT

Actionable Analysis

The application reports a classification, confidence, regional scores and a Grad-CAM visualization.
